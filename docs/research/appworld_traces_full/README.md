# Full AppWorld trajectories

This directory contains the complete raw artifact directories for the 12 final normal AppWorld runs used in the baseline comparison. It includes the full model prompts/messages, tool arguments and outputs, event metadata, evaluator output, and generated analysis artifacts.

The run folders are copied from the local experiment ledger and are named by task, configuration, and final attempt. Attack runs and abandoned earlier attempts are not included. The credentials and identifiers in this bundle are the synthetic AppWorld values used by the experiment, as confirmed by the experiment owner. Project `.env` files and provider credentials are not included.

For a smaller review-friendly version, see [`../appworld_traces_redacted/`](../appworld_traces_redacted/).
