# AppWorld redacted trajectory bundle

This directory contains the 12 final normal AppWorld runs. It preserves event order, actors, tool names, statuses, token counts, timing, official evaluation, handoff counts, mutation counts, and output hashes.

Removed from every file: API keys, access tokens, passwords, phone numbers, raw tool arguments, raw tool outputs, SMS text, complete prompts, Agent message contents, and final answer text. The original files remain local under `artifacts/appworld_baselines/` and are not part of this bundle.
