# Pilot 08: native proposal boundary implementation

Base `origin/main`: `7d557dc793221906a46a1f83d4e5888fcc5c28d2`.

This branch selectively ports the Pilot 07 Artifact intervention and frozen-initial-topology support (Pilot 07 commits `9299d633711aac02b632dd5f36924364483bf8ad` and `fb744387d50f368cab58c3b6c44a5c8241e49bbf`), plus the WorkBench sandbox and executor signature export/import from Pilot 06 (`d80cd57339f6ac16589a08ffa8c726a8077a18e5`). It adds `checkpoint.py`, a minimal split at the native Planner proposal boundary in `engine.py`, a same-checkpoint KEEP/MUTATE continuation, and a budgeted runner. No Auditor, Planner prompt, STOP rule, WorkBench ground truth, or evaluator rule was changed.

The checkpoint is captured **after** the native Auditor and Planner have produced a legal proposal and **before** native application. It includes the full logical Agent state (messages, Artifacts, interaction history, evidence ledger, controller decisions, topology, current turn, short-term playbook, prior token-bearing trace), the frozen native proposal, all seven WorkBench sandbox tables, the executor's executed-call signature set, and the consumed Artifact-intervention state. Live LLM handles, tool closures, and descriptor objects are excluded. Restoration rebuilds tool handlers through the normal WorkBench factory and binds them to independent sandboxes.

`scripts/validate_native_checkpoint.py` first passed a free component-level two-restore check. That result alone was **not** a strict paired causal result. The later live `multi_domain_11` and `multi_domain_17` checkpoints each passed `LIVE_BOUNDARY_TWO_RESTORE_PASSED` in `restore_validation/<task_id>.json`, and each completed real KEEP and MUTATE continuations. The source hashes, pre-fork state, and effects are audited in `paired_summary.csv` and `REPORT.md`. `multi_domain_19` produced no legal proposal in its capture run and has no pair. Independent same-seed reruns were never used as a substitute.

The live validation also previews the first continuation model input on each branch and aborts before making an API call. It checks that this preview did not replay a historical WorkBench write. The complete preview is saved under `results/pilot08_counterfactual/next_prompt_previews/`. KEEP and MUTATE both consume the frozen proposal's repair opportunity; KEEP does not gain an extra later Repair merely because it has no new topology version.

The frozen Pilot 07 task, payload, initial topology, model settings, and source hashes are recorded in `results/pilot08_counterfactual/manifests/<task_id>.json`. The task 11 proposal contains graph operations `set_group_pattern` and `add_agent`; the task 17 proposal contains only `set_context_policy`. The former is the sole effective graph pair, while both are valid native same-state pairs. The seven real Pilot 08 episodes and their conservative upper cost are retained in `cost_ledger_snapshot.json`; complete raw trajectories, metadata, traces, evaluations, checkpoints, and logs are committed with the branch.
